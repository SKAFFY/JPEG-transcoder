# JPEG-transcoder

Реализация собственного кодера и декодера для JPEG без потерь (бит‑в‑бит восстановление) в рамках лабораторной работы.  
Код написан на Go, не использует сторонних библиотек для сжатия.  
Проект включает Makefile для автоматической загрузки тестовых датасетов (jpeg30, jpeg80), сборки эталонных C++ утилит и Go‑программ, E2E‑теста и инструмента анализа сжатия.

**Требования**

- Go 1.21 или выше
- GNU Make
- wget
- p7zip (команда `7z`)
- g++ (для сборки C++ эталонов, не обязательно для Go‑части)

**Сборка**

- `make all` — полная сборка: C++ эталоны, Go‑кодер/декодер, загрузка датасетов.
- `make build-go` — сборка только Go‑программ: jpeg_encoder, jpeg_decoder, jpeg_e2e_test, jpeg_analysis.
- `make build-windows` — кросс‑компиляция Go‑программ под Windows (amd64). Результат в папке bin/windows.
- `make setup-datasets` — скачать и распаковать архивы jpeg30.7z и jpeg80.7z в папку test.

**E2E‑тест (бит‑в‑бит проверка)**

E2E‑тест кодирует каждый JPEG из test/jpeg30 и test/jpeg80 в сжатый формат, затем декодирует обратно и сравнивает с оригиналом.

- `make test-e2e` — использует скомпилированные бинарники.
- `make run-e2e` — быстрый запуск через go run (без предварительной компиляции).
- `make test-e2e-custom DIR30=./my30 DIR80=./my80` — запуск с пользовательскими путями к папкам с изображениями.

**Анализ сжатия**

Программа `jpeg_analysis` (исходник в `cmd/analysis`) кодирует каждый JPEG из папок jpeg30 и jpeg80 и выводит таблицу размеров исходных и сжатых файлов, коэффициент сжатия и итоговые суммы.

- `make analysis` — вывести таблицу в консоль.
- `make analysis-save` — сохранить таблицу в файл `test/reports/analysis_YYYYMMDD_HHMMSS.txt`.

Таблицу можно скопировать в отчёт.

**Ручной запуск кодера и декодера**

- Кодирование: `bin/jpeg_encoder -f input.jpg -t output.bin`  
  (параметры: `-f` исходный JPEG, `-t` выходной сжатый файл).
- Декодирование: `bin/jpeg_decoder -f output.bin -t restored.jpg`

После декодирования restored.jpg должен быть идентичен input.jpg байт в байт.

**Юнит‑тесты**

`make test` запускает go test ./...

**Очистка**

- `make clean` — удаляет папку bin.
- `make clean-cpp` — удаляет third_party/parser и third_party/jpeg-source.
- `make clean-datasets` — удаляет test/jpeg30 и test/jpeg80.
- `make clean-reports` — удаляет папку test/reports.
- `make clean-all` — удаляет всё перечисленное, а также временные архивы в /tmp.

**Получение данных для отчёта**

Для построения таблицы размеров сжатых файлов (15 изображений, QF=30 и QF=80) выполните:

`make analysis-save`

Файл с таблицей появится в `test/reports/`. Суммарные значения указаны в строке TOTAL.
